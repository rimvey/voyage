# voyage — 1장 시스템 보안 설계 워크벤치

계정·비밀번호 요건 체크리스트, 5×6 설계 매트릭스, 정책 슬라이더를 한 화면에서 다루는 실습용 웹 페이지입니다.
슬라이더를 움직이면 양호/취약 판정, 공격 성공까지 걸리는 시간, 리눅스 설정 문구가 바로 바뀝니다.

## 파일

| 파일 | 설명 |
|---|---|
| `SPEC.md` | 개념, 판정 규칙, 설정 문구 생성 규칙, 함정 테스트. 코드는 이 파일의 규칙만 구현한다 |
| `index.html` | 워크벤치 본체 (HTML/CSS/JS 한 파일, 외부 의존성 없음) |
| `serve.sh` | 정적 서버 실행 스크립트 |

## 실행

```
./serve.sh        # 기본 포트 8000
./serve.sh 9000   # 포트 지정
```

실행 후 `http://localhost:8000/index.html` 로 접속합니다. `python3`만 있으면 됩니다.

## 화면 구성

- 왼쪽: 계정 5개·비밀번호 5개 요건 체크리스트 (표 1-6, 1-7)
- 가운데: 5계층 × 6기술영역 설계 매트릭스와 구현 준비 점검 (표 1-21, 1-22)
- 오른쪽: 정책 값 슬라이더 6개, 공격 시간, 설정 문구 (표 2-1, 2-5~2-9)
